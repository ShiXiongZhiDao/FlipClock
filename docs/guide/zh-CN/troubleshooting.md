# 故障排查

简体中文 · [English](../en/troubleshooting.md)

先看具体报错或它出现在哪一页。没有源码证实的原因，这里写成「可以检查什么」，不写成结论。

## 装不上或打不开

- **首次运行被 SmartScreen 拦下** —— 安装包没有代码签名证书。点「更多信息 → 仍要运行」。
  更新包的完整性由单独的签名保证。
- **缺少 WebView2** —— Windows 10/11 上很少见。装 Microsoft Edge WebView2 Runtime 再启动。
- **便携版打不开** —— 先把压缩包完整解压；在 zip 里直接运行 `FlipClock.exe` 不行。

## 屏保不出现

- **没安装** —— 设置 → 屏保 →「安装屏保」。
- **从 Windows 列表里消失了** —— 列表只显示 `System32\*.scr` 加当前选中项。换成别的屏保
  就会移除 FlipClock；重新安装一次就能选回来。
- **Windows 里的预览是空白** —— `/p` 系统预览明确不支持。用应用内的「预览屏保」。
- **提示屏保是旧版/需要更新** —— 先关掉正在跑的屏保，再点「更新屏保」。
- **等待时间不生效** —— 那是 Windows 的设置，不是 FlipClock 的。从屏保页打开它。

## 关了窗口托盘图标还在

这是默认行为：关闭只是隐藏到托盘。右键图标 →「退出」才结束进程；或者在
「系统 → 启动与窗口」里关掉「关闭窗口时最小化到托盘」。1.1.0 的这个开关重启后会失效，
1.1.1 已修复。

## 更新失败

- 安装版需要能访问 Gitee 或 GitHub。先试 Gitee；只有 Gitee 返回错误才换 GitHub，
  超时不会回退。
- 便携版能检查更新，但没有安装器可执行。手动下载新的 zip。

## 字体不对

- 支持 `ttf`、`otf`、`woff`、`woff2`，单文件不超过 32 MB，最多 32 款。
- 删除字体后，用过它的主题回退到 **Bebas Neue**。
- 有些字体数字高低不一。应用会提醒，但仍然接受；觉得歪就换一款。

## 图片不显示

- 导入的图片会复制进配置目录。移动原文件没关系；在应用里删除是不可撤销的。
- 支持 `png`、`jpg`、`jpeg`、`webp`。
- 提示对比度低，说明数字与卡片亮度太接近，改其中一个。

## 多显示器

支持「主显示器」和「所有显示器」，不支持指定子集。运行中增减显示器，屏保会重建窗口。

## 配置导入失败

- 只接受 FlipClock 1.1.1 导出的包（格式 1、schema 4）。
- 导入会合并自定义主题与字体，不删除本机已有内容；重名会变成副本。
- 需要回退时，看配置目录里的 `backups\pre-import.zip`。
