# 备份与迁移

简体中文 · [English](../en/backup-and-restore.md)

配置包把主题、字体和偏好带到另一台电脑。它不是云备份：文件存在你选择的位置。

## 导出

「系统 → 配置迁移 → 导出配置包…」

文件名是 `FlipClock-config-YYYYMMDD.zip`。导出永远是全量，没有可勾选项。

包含：

- 全部自定义主题，连同它们的背景图与纹理图
- 整个导入字体库
- 每个主题的钟面配置（制式、日期、秒数、冒号、排布、字体、缩放、亮度、音效）
- 当前主题
- 偏好：界面语言、界面外观、显示器策略、无参数启动、关闭后留在托盘

不包含屏保注册信息与回滚点，也不包含开机自启——那两项在注册表里。

## 导入

「系统 → 配置迁移 → 导入配置包…」，选 zip，再勾选要恢复的内容：

| 分组 | 行为 |
| --- | --- |
| 内置主题的钟面配置 | 覆盖同名配置 |
| 自定义主题 | 合并；内容相同的映射到已有主题，名字或 id 冲突时导入为副本 |
| 字体 | 按内容合并，重复的直接复用 |
| 偏好 | 覆盖四段偏好 |

当前主题在勾选范围内时，导入后会成为当前主题。

写盘之前，应用会先把现有配置备份到
`%APPDATA%\com.dd.shixiongzhidao\backups\pre-import.zip`。备份失败就中止导入。

## 版本兼容

接受格式 1、schema 4 到 5 的配置包（FlipClock 1.1.2 起导出 schema 5）。更老或更新的包
会被明确拒绝，没有降级或迁移路径。

## 上限

最多 36 个自定义主题、32 款导入字体。超出的条目按导入顺序跳过，并在结束时报告。
