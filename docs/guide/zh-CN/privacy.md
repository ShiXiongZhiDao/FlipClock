# 隐私说明

简体中文 · [English](../en/privacy.md)

FlipClock 不收集个人隐私数据。没有账号，不收集姓名或邮箱，没有设备或安装标识，
也不读取你的文档、剪贴板、摄像头或麦克风。

## 匿名使用统计

官方构建会发送三类匿名事件：应用启动、钟面配置快照（主题与翻页卡排布）、安装屏保。
不发送任何自由文本。一个临时的会话标识用来把同一次运行的事件归到一起；它只存在内存里，
不写盘，也不是用户标识。事件发到第三方统计服务 Aptabase（`eu.aptabase.com`）。
从源码自行构建、没有配置 app key 时，一条也不发。应用内没有开关。

## 其他网络请求

- **检查更新** —— 设置窗口出现约 5 秒后自动一次，点「检查更新」时也会。先试 Gitee，
  失败再试 GitHub。
- **关于页图片** —— 打开「系统」页时，从 GitHub 或 Gitee 加载三张图片。

没有账号、没有同步、没有云存储。

## 本地数据

设置、主题、字体与导入的图片都在 `%APPDATA%\com.dd.shixiongzhidao\`。导入的文件会复制
到这里，之后移动原文件不影响使用。FlipClock 不写日志，也不生成崩溃报告。

## 第三方基础设施

上面这些服务可能按它们自己的政策处理 IP 等连接信息。本项目控制不了它们的保留策略。
