# 把 FlipClock 当成屏幕保护程序

简体中文 · [English](../en/screensaver.md)

FlipClock 是真正的 Windows 屏保，不是视频，也不是锁屏替代品。`FlipClock.scr` 与应用是
同一个二进制；Windows 到点用 `/s` 拉起它。注册只影响当前用户。

## 安装

1. 打开「设置 → 屏保」。
2. 点「安装并设为当前屏保」。
3. 到 Windows 里设等待时间：「屏保 → 打开 Windows 屏保设置」。

安装具体做了三件事：

- 把正在运行的 `FlipClock.exe` 复制成 `%LOCALAPPDATA%\FlipClock\FlipClock.scr`。
- 在 `HKCU\Control Panel\Desktop` 写两个值：`SCRNSAVE.EXE`（上面的路径）与 `ScreenSaveActive`（`1`）。
- 把你原来的屏保记录成回滚点。

不需要管理员权限。FlipClock 不写 `System32`，也不替代 Windows 锁屏。

## 为什么它会从 Windows 列表里消失

Windows 的屏保列表只显示 `System32\*.scr` 里的文件**加上当前选中的那一个**。FlipClock
是靠「当前值」这个身份进列表的，不是靠文件位置。换成别的屏保，它就会消失——想再选回来，
重新点一次「安装并设为当前屏保」。

让它常驻列表只能写 `System32`，那需要管理员权限；本项目刻意不做。

## 测试与退出

- Windows 对话框里那个小「预览」是空白：`/p <HWND>` 系统预览钩子明确不支持。
- 用应用里的「预览屏保」，或运行 `FlipClock.exe /s`。
- 任意按键、任意鼠标键、或光标移动超过 3 像素，整个会话退出。启动后 700 毫秒内不算，
  避免手抖把屏保关掉。

## 多显示器

「屏保 → 多显示器」提供「主显示器」和「所有显示器」。指定显示器子集暂不支持。
运行期间增减显示器或改分辨率，会话会自己重建窗口。

## 恢复、重装、版本不匹配

- 「恢复原屏保」把选择还给安装前记录的回滚点。
- 卸载 FlipClock 时安装器会自动恢复。
- 启动时应用会比对已注册的 `.scr` 与自己，不一致就刷新副本。刷新失败（屏保正在跑、
  文件被占用）时，屏保页显示「版本不匹配」——关掉屏保，再点「重新部署屏保组件」。

## 命令行

| 参数 | 作用 |
| --- | --- |
| *(无参数)* | 按「无参数启动」进入设置窗口或全屏时钟 |
| `/c` | 打开设置窗口 |
| `/s` | 启动屏保，任意输入退出 |
| `/p <HWND>` | 不支持——进程不建窗口，直接退出 |
| `--fullscreen` | 主屏全屏时钟，置顶 |
| `--tray` | 只驻留托盘，不弹窗口；开机自启用它 |
| `--restore-screensaver` | 卸载器专用：把屏保选择恢复成安装前的样子 |
| `--debug-windowed` | 仅开发用：屏保降级成 960×540 窗口 |

`/s` 与 `/p` 会绕过单实例限制，保证 Windows 随时能拉起屏保。
